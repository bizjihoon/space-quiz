# AGENTS.md

## Project overview
This project is a lightweight static web app for a space-themed quiz. The app is intentionally simple and self-contained: all behavior and styling live in a single file, `index.html`.

## Working rules
- Keep the project dependency-free and serverless.
- Prefer updating `index.html` for HTML, CSS, and JavaScript changes.
- Do not introduce frameworks, build tools, or package installs unless explicitly requested.
- Preserve the single-file structure and minimal setup.
- Keep the interface colorful, accessible, and easy to use on desktop and mobile.
- Maintain keyboard accessibility: visible focus states, clear contrast, and semantic controls.
- Preserve existing behavior unless the task specifically asks for a feature change.

## Verification
- Check the app by opening `index.html` directly in the browser when validating UI changes.
- Use small, focused updates rather than broad rewrites.
- Keep code readable and easy to maintain for a tiny static project.
